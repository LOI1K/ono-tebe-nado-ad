# Оно тебе надо

Учебный проект первого спринта курса «Веб-разработчик» от Яндекс Практикума.

**«Оно тебе надо»** — одностраничный сайт аукциона необычных вещей, в ценность которых когда-то никто не верил.

## О проекте

Сайт состоит из пяти основных разделов:

- **Header** — навигация, логотип и контактная информация.
- **Cover** — обложка с названием аукциона и кнопкой «Сделать ставку».
- **Lots** — три карточки лотов с изображениями и описаниями.
- **About** — информация об идее и особенностях аукциона.
- **Footer** — контакты, навигация и ссылки на социальные сети.

Вёрстка выполнена по макету Figma.

## Используемые технологии

- HTML5 — семантическая разметка страницы.
- CSS3 — оформление и стилизация элементов.
- Flexbox и CSS Grid — построение сеток и расположение блоков.
- CSS-позиционирование — работа со слоями и затемнениями.
- Локальный шрифт Raleway.
- SVG и растровые изображения.

Проект реализован без JavaScript и сторонних библиотек.

## Запуск проекта

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/LOI1K/ono-tebe-nado-ad.git
   ```

2. Открыть папку проекта.
3. Открыть файл `index.html` в браузере.
